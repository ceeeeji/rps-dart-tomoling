Description

This is basically just the rock, paper, scissor game - but it is played through dart's cli :D

How to Run

IMPORTANT!!: Make sure that Dart is installed on your computer.

Then open the terminal in the project folder and run:

dart rock_paper_scissors.dart


Features:
Rock
Paper   
Scissors
Two-player game
Has replay option
Able to personalize your name
Winner, loser, and draw detection
